EventForce Management System

A web-based event management system for planning events, registering attendees, assigning team members and tracking budgets from one dashboard.

Naan Mudhalvan project.

Live demo: https://Shavez26.github.io/eventforce-management-system/

Overview

EventForce helps organizers plan events, register attendees, assign team members and track spending from one dashboard. It replaces scattered spreadsheets and paper lists with a single, easy-to-use application. It is suited to college fests, seminars, workshops and career fairs.

Problem Statement

Organizers often manage registrations, volunteer duties and budgets in separate files. This leads to duplicate entries, overbooked venues, unclear responsibilities and overspending. EventForce keeps all of this information together and up to date.

Features
Dashboard: live totals for events, registrations, check-ins, team members and remaining budget, with a per-event summary.
Event management: create events with date, venue, capacity and budget, update their status (Planned, Live, Completed, Cancelled) and delete them.
Attendee registration: register attendees for an event, check them in on the day, and filter the list by event. Registration stops automatically when an event reaches capacity.
Team management: assign coordinators, volunteers, registration desk staff, logistics, security and hospitality to each event.
Budget tracking: record expenses against an event and see budget, amount spent and balance left. An overspent event is shown in red.
Data saved in the browser: entries stay available after refreshing the page, and the Dashboard has a button to reset to sample data.
Responsive design: works on desktop and mobile, with automatic light and dark themes.
